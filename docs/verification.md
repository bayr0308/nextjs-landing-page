# Проверки

Дата: 19 октября 2026.

## Автоматические проверки

- `pnpm format` и `pnpm format:check` — Oxfmt.
- `pnpm lint` — Oxlint без предупреждений; React, hooks, TypeScript, Next.js, JSX accessibility.
- `pnpm typecheck` — генерация типов и TypeScript.
- `pnpm build` — production build через Webpack, статически подготовленная главная страница.

## Браузер

Chrome через отдельную сессию agent-browser. Проверены 390 × 844, 768 × 1024 и 1440 × 1000; инспектор использует 1440 × 900 для настольных листов.

| ----------------------- | --------------------------------------------------------------------------------------------------- |

Для текста поверх фотографий axe-core не может автоматически определить фон и помечает контраст как ручную проверку. Текст и затемнение осмотрены на всех трёх ширинах; это не утверждение о полной сертификации WCAG.

Скриншоты и сырые результаты сохранены локально в игнорируемой `.qa/`. `docs/preview.jpg` — финальный первый экран. Визуальные исключения и два раунда осмотра описаны в `design-notes.md`.

Safari/Firefox, реальные мобильные устройства и внешний хостинг отдельно не проверялись. Настоящей серверной отправки нет по условию задания.
