# ГРАНЬ Девелопмент

Законченный демонстрационный лендинг вымышленного застройщика. Интерфейс и контент на русском языке. Компания, проекты, цены, сроки и показатели вымышлены; это явно указано на странице.

## Запуск

Нужны Node.js 22+ и pnpm 10.18.3.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте [локальное превью](http://127.0.0.1:3000).

```sh
pnpm build
pnpm start
```

`start` запускает собранную production-версию на том же адресе. Сначала остановите `dev`, если он занимает порт 3000. Для другого порта: `pnpm start --port 3001`.

## Стек и команды

Next.js 16.4.2 (App Router), React 19.3.1, TypeScript 5.9.3, Tailwind CSS 4.3.3, Oxfmt 0.73.0, Oxlint 1.88.0. Зависимости закреплены lockfile.

| Команда             | Назначение                                                   |
| ------------------- | ------------------------------------------------------------ |
| `pnpm dev`          | Локальная разработка                                         |
| `pnpm build`        | Production build                                             |
| `pnpm start`        | Запуск production build                                      |
| `pnpm lint`         | Oxlint: React, hooks, Next.js, TypeScript, JSX accessibility |
| `pnpm format`       | Форматирование Oxfmt                                         |
| `pnpm format:check` | Проверка форматирования                                      |
| `pnpm typecheck`    | Генерация типов Next.js и `tsc --noEmit`                     |

Использован поддерживаемый режим `--webpack`: Turbopack в данном Windows-окружении аварийно завершался при запуске процесса обработки PostCSS. Webpack dev и production build проверены. У TypeScript выбрана стабильная совместимая версия 5.9.3.

## Что реализовано

- Крупный архитектурный первый экран, показатели масштаба, асимметричный каталог из четырёх проектов, подход к строительству, тёмный блок о компании, консультация и подвал.
- Фильтры «Все», «В продаже», «Скоро старт», «Сдан».
- Модальное окно на нативном `dialog`: удержание фокуса, закрытие Escape/кнопкой/кликом по фону, возврат фокуса, блокировка прокрутки фона.
- Переход из проекта к форме с выбором соответствующего ЖК и фокусом в поле имени.
- Проверка имени и российского телефона, сообщения об ошибках, явное подтверждение отсутствия отправки.
- Мобильное меню, якорные ссылки, видимый фокус, подписи полей, live region результата, `prefers-reduced-motion`.
- Локальные шрифты Manrope с кириллицей, пять локальных WebP-изображений, адаптивная оптимизация через `next/image`, метаданные, noindex и русская страница 404.

## Структура

- `src/app/page.tsx`, `layout.tsx` — Server Components; статическое содержимое рендерится на сервере.
- `src/components/` — небольшие компоненты; клиентская логика ограничена интерактивностью.
- `src/data/projects.ts` — сведения о ЖК и навигация.
- `src/app/globals.css` — Tailwind, дизайн-токены, адаптивные стили и анимации.
- `public/images/` — готовые изображения. Внешние сервисы во время просмотра не нужны.
- `docs/assets.json` — исходные промпты и происхождение визуалов.
- `docs/design-notes.md` — арт-дирекция и визуальная проверка.
- `docs/verification.md` — результаты проверок и границы проверки.

Форма не содержит API-маршрута, не вызывает `fetch`, не сохраняет данные в cookies или localStorage. Ввод остаётся в памяти открытой страницы. Настоящие контакты и сторонняя аналитика не добавлены.
